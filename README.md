# Sanjay Krishna OB - Portfolio

Personal portfolio website showcasing AI, Cybersecurity, and Cloud projects.

## 🚀 Tech Stack
- HTML5
- CSS3 (with Geist Mono font)
- Vanilla JavaScript
- Deployed on Vercel

## 📦 Deployment

This site is configured for automatic deployment on Vercel.

### Deploy to Vercel:
1. Push this repository to GitHub
2. Import the project in Vercel
3. Deploy automatically

Or use Vercel CLI:
```bash
vercel
```

## 📁 Project Structure
```
├── index.html          # Main HTML file

├── profile.png         # Profile image

├── vercel.json         # Vercel configuration
```
